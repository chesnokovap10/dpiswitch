# Правила работы

- Пуш, создание или публикация релиза и деплой выполняются только по явной команде пользователя. Разрешение на одну операцию не означает разрешения на остальные.
- Изменение кода, сборка и тесты сами по себе не разрешают пуш, релиз или деплой.
- Версию для релиза менять только по команде пользователя; до этого сохранять текущую версию.
- В дереве пресетов категория «Прочее» всегда последняя. Остальные категории и сервисы внутри категорий сортируются по алфавиту на выбранном языке интерфейса.
